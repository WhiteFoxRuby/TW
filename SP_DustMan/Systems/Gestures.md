# Gestures — жесты: алфавит ввода

> [!summary]
> Жесты — алфавит, из которого строятся все действия за столом. Каждый жест — отдельный тип ввода мышью/тачпадом; из их комбинаций складываются процедуры ремонта. Дизайн описывает **8 жестов**, срез реализует **6** (вращение, протирка, качание, drag, клик, зум). Все пороги — в `GestureConfig.asset`, не в коде: их крутят на плейтестах. **Это ключевая гипотеза игры: если жесты не ощущаются — дальше не идём, а крутим пороги.**

## Алфавит жестов

| Жест | Источник | Как | Применение | Срез |
|---|---|---|---|---|
| **Вращение** | UCRS, Assemble With Care, Potion Craft | Зажать на точке и водить по кругу. По часовой — закрутить, против — открутить. Недокрутил — не держит, перекрутил — сорвал резьбу | Винты, болты, гайки; намотка нити; проворачивание заевшего механизма; полировка | ✅ |
| **Качание** (возвратно-поступательное) | UCRS (трещотка, насос) | Зажать и двигать вперёд-назад / влево-вправо; ощущение физического усилия | Пиление, шлифовка наждачкой, насос, расшатывание застрявшей детали | ✅ |
| **Перетаскивание** (drag & drop) | Papers Please, AWC, Strange Horticulture, Unpacking | Взял — понёс — положил, со снапом к слоту | Перемещение предметов и деталей, извлечение из корпуса, перенос из ящика запчастей, инструменты со стола | ✅ |
| **Точное перетаскивание** (по траектории) | AWC (провода), Potion Craft (карта) | Важен путь, не только концы: протащить через конкретные точки | Протяжка нити через бусины, прокладка провода, ремень через шкивы | ⬜ later |
| **Удержание** (hold) | Potion Craft (кипячение), UCRS (заправка) | Зажать и держать; есть оптимальный момент отпускания — передержал = испортил | Склейка, пайка (недогрел/перегрел), сушка, пропитка | ⬜ later |
| **Клик / серия кликов** | Trash Goblin (порода) | Один клик или серия по зоне | Удары молотком, скалывание, простукивание для диагностики | ✅ (клик) |
| **Щипок / зум** | AWC | Сведение пальцев; на мыши — колесо | Переключение уровней осмотра: общий вид → рабочий → лупа | ✅ |
| **Протирка** (wipe) | Trash Goblin (губка), PowerWash Simulator | Водить курсором по поверхности — очищается там, где прошёл; иногда несколько проходов | Грязь тряпкой, ржавчина наждачкой, нанесение масла/лака, протирка линзы | ✅ |

> [!important] Доступность
> Круговое вращение (Potion Craft, AWC, UCRS) глубоко удовлетворяет, но вызывает напряжение запястья при долгих сессиях. Решение, подтверждённое несколькими тайтлами: **альтернатива «удерживай для выполнения»** наряду с жестом. В срезе не реализована — [[Reference/Open Questions#Альтернатива «удерживай» для жестов]].

## Реализация в срезе

Ядро — `Assets/Scripts/Gestures/GestureCore.cs`: три чистых трекера без Unity-зависимостей (кроме `Mathf`/`Vector2`), которые верстак использует напрямую. `GestureRecognizer` — MonoBehaviour-обёртка для дебаг-сцены и простых зон.

```csharp
public enum GestureKind { Rotate = 0, Wipe = 1, Rock = 2, Drag = 3, Click = 4, Zoom = 5 }
```

### Вращение — `RotationTracker`

Накапливает угловую дельту вектора курсор→центр за кадр. **Против часовой — положительно** (выкручивание), по часовой — отрицательно. `Turns = AccumulatedDeg / 360`.

- Дельты меньше дедзоны (`rotationDeadzoneDegPerFrame = 0.5°`) **копятся** — референсный угол не сдвигается, поэтому медленное вращение не теряется (правка ревью: раньше дедзона «глотала» медленные обороты).
- Ближе `rotationMinRadius = 0.15` к центру угол нестабилен — шаг пропускается, при выходе из радиуса угол перебазируется.
- Винт: `screwTurnsToRemove = 2` оборота CCW = выкручен. При затяжке больше `2 + overtightenExtraTurns (2)` оборотов CW — **перекрут**, `OvertightenCount++` (штраф качества), один штраф на закручивание. Захват — в радиусе `screwEngageRadius = 0.7`.

```csharp
public class RotationTracker
{
    public void Engage(Vector2 rotationCenter, Vector2 cursor);
    public float Step(Vector2 cursor, float deadzoneDeg, float minRadius = 0f); // дельта за кадр, °
    public float AccumulatedDeg { get; }   // CCW положителен
    public float Turns => AccumulatedDeg / 360f;
}
```

### Протирка — `WipeGrid`

Маска загрязнения: grid **8×8** (`wipeGridSize`) поверх прямоугольника модуля в мировых координатах. Ячейка очищается, если её центр попал в радиус кисти (`wipeBrushRadius = 0.3`). Дефект снят при **90%+** очищенных (`wipeCompleteFraction`).

- `WipeSegment(from, to, radius)` интерполирует между кадрами — быстрые мазки не пропускают ячейки.
- `PreClear(count)` восстанавливает частичный прогресс после выхода со сцены по Q.
- `CellCleared(ix, iy)` — событие для снятия визуала ячейки.

### Качание — `RockTracker`

Смена знака дельты по доминирующей оси. Ход засчитан, если размах от якоря ≥ `rockMinAmplitude = 0.35`. Одно «качание» = два хода (туда-обратно): `Rocks = Strokes / 2`. Готово при `rocksRequired = 6` качаний. Зона захвата — `rockEngageRadius = 0.9`. `Finish()` при отпускании досчитывает последний ход; на верстаке накопленные ходы не теряются между захватами (`rockStrokesBase`).

### Drag, клик, зум

- **Drag** — стандартный, снап к слоту в радиусе `dragSnapRadius = 0.6` (подсветка валидного слота). Запасные линза и батарейки, винты со стола в отверстия, инструменты к точке работы.
- **Клик** — тривиален; в срезе: кнопка фонаря на проверке, плоскогубцы (клик-захват + drag).
- **Зум** — колесо мыши: `zoomMin = 2` … `zoomMax = 6`, шаг `0.5` (ortho size камеры).
- **Осмотр** — горизонтальный drag по собранному фонарю вращает его: `inspectRotateDegPerUnit = 40°` на мировую единицу.
- **Лупа** — держать над дефектом `magnifierRevealSeconds = 0.4` с в радиусе `magnifierRadius = 0.8` → дефект `Revealed`.

### Общие правила на верстаке

- Инструмент берётся со стола drag'ом и подносится к точке работы; **ПКМ** или клик по лотку возвращает его. ПКМ также отменяет активный жест.
- Клики по uGUI не проваливаются в мир (`EventSystem.IsPointerOverGameObject`).
- Ошибки жестов (перекрут, лишняя царапина наждачкой по чистому месту) пишутся в телеметрию `GestureError` и в счётчик фрустрации режиссёра ([[Director/Director#Индексы]]).

## Дебаг-сцена `GestureDebug`

Этап 2 скоупа: 6 площадок с индикаторами прогресса каждого жеста, без предмета. **R** — сброс. Приёмка — человек руками подтверждает, что вращение / протирка / качание детектятся надёжно и не срабатывают друг вместо друга. Приёмка ещё не проводилась ([[Reference/MVP Scope#Этапы и критерии приёмки]]).
