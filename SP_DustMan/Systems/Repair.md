# Repair — ремонт: три фазы, категории, процедуры

> [!summary]
> Самое мясо игры. Каждый предмет — 2D-схема из модулей, каждый модуль может быть исправен / повреждён / отсутствует / заражён. Ремонт идёт в **три фазы: Осмотр → Работа → Проверка**. В UCRS работает именно то, что поломка каждый раз комбинаторная, а не скриптовая — но у UCRS есть гримуар. У мусорщика его нет: **он учится сам**, и его память — блокнот. Главная гипотеза среза: жестовый ремонт за столом приятен сам по себе.

## Три фазы

### Фаза 1 — Осмотр

Предмет лежит на столе. Игрок вращает его (drag), осматривает со всех сторон, зумит. Видимые повреждения заметны сразу — трещина в корпусе, отсутствующая пуговица, оборванный провод. Скрытые — **только через лупу или разборку**. Игрок сам решает, что здесь не так. **Никакого маркера «вот тут поломка».** Это диагностика UCRS, но без гримуара — через наблюдательность.

Три уровня осмотра (модель Strange Horticulture): обзор (весь предмет) → рабочий вид (текущая панель) → режим лупы (микротрещины, качество деталей, чернота).

### Фаза 2 — Работа

Разборка модуль за модулем. Жесты зависят от действия: вращение для винтов, drag для извлечения, протирка для чистки, удержание для склейки и пайки ([[Systems/Gestures]]). Инструменты физически лежат на столе и выбираются перетаскиванием к точке работы ([[Systems/Tools]]). Каждый тип предмета — свой набор: ожерелью нужны плоскогубцы и игла, фонарю — отвёртка и паяльник.

### Фаза 3 — Проверка

Собрал — проверяешь. Фонарь должен включиться, ожерелье — застегнуться, шкатулка — заиграть. Если что-то собрано неправильно или пропущено — предмет не проходит проверку и **показывает симптом**: фонарь мигает → плохой контакт; ожерелье расстёгивается → застёжка не держит. Возвращаешься и ищешь. **Штрафа за провал проверки нет** — бесстрессовость Trash Goblin: ошибки не наказываются, пока не продал.

## Структура предмета

Каждый объект — 2D-схема из модулей. Ожерелье: нить (основа), застёжка (механизм), пуговицы (элементы), обмотка (отделка). Фонарь: корпус, линза, лампа, батарейный отсек, кнопка. Состояния модуля: **исправен / повреждён (чинится) / отсутствует (замена) / заражён чернотой (очистка)**. Модель данных среза — [[Systems/Items and Defects]].

## Категории предметов и типы поломок

Категория определяет инструменты и жесты. Внутри категории — 5–7 типов поломок, каждый с уникальным набором шагов.

### Механика

Часовые механизмы, музыкальные шкатулки, замки, зажигалки, механические игрушки, таймеры.

| Поломка | Диагностика | Ремонт |
|---|---|---|
| Заклинивший механизм | шестерня не проворачивается | разборка (отвёртка) → извлечь шестерни (плоскогубцы) → чистка осей → сборка; **порядок шестерён важен** |
| Сломанная пружина | не заводится | разборка → старая пружина → новая (точный drag на два крючка); пружина из запаса или с токарного станка |
| Смещённые шестерни | работает с перебоями | лупа → найти незацепленную → поправить |
| Коррозия осей | тугое движение, скрежет | наждачка (качание) → масло (точный drag капельницы) |
| Отсутствующие детали | пустые посадочные места | подобрать из запаса; неидеальное совпадение = работает хуже |

### Электроника

Фонари, радиоприёмники, электротаймеры, детекторы, примитивные компьютеры, осветительные приборы.

| Поломка | Диагностика | Ремонт |
|---|---|---|
| Обрыв провода | мультиметр показывает разрыв | найти под лупой → обрезать (кусачки) → зачистить (мелкая наждачка) → припаять перемычку |
| Окисленные контакты | высокое сопротивление | зачистка наждачкой или растворителем — быстро *(в срезе)* |
| Перегоревший элемент | почерневший элемент на плате | выпаять → впаять новый из запаса |
| Разряженный источник питания | не включается, цепь цела | открыть отсек → извлечь → установить новый; если контакты окислены — плюс чистка *(в срезе)* |
| Неправильная проводка | мигает свет, искажён звук | проследить по схеме в блокноте, переподключить — пазл на логику |

### Текстиль и украшения

Ожерелья, браслеты, сумки, ремни, куклы, набивные игрушки, одежда с механикой.

| Поломка | Диагностика | Ремонт |
|---|---|---|
| Оборванная нить / шнур | концы болтаются | обрезать (ножницы) → вдеть → протянуть через элементы (точный drag) → узлы (вращение); длина нити важна |
| Сломанная застёжка | не защёлкивается | крючок — выпрямить плоскогубцами; защёлка — разобрать, почистить, пружинка; завязка — перевязать |
| Отсутствующие элементы | пустые места в узоре | подобрать из запаса (размер, цвет, форма → качество) → закрепить |
| Загрязнение ткани | пятна, потемнение | ванна (drag + удержание) или кисть; деликатные ткани не переживут ванну |
| Распутывание | клубок, узлы | последовательный drag нитей через петли; тянул резко — порвал; терпение вознаграждается |

### Бытовое

Фонари, фляги, ножи, инструменты, посуда, замки, очки, зеркала.

| Поломка | Диагностика | Ремонт |
|---|---|---|
| Вмятины на корпусе | визуально | молоток + настольная наковальня, удары с обратной стороны; точность важна |
| Тупое лезвие | не режет тестовый материал | заточка на бруске под правильным углом (качание) |
| Разбитое стекло / линза | визуально | извлечь осколки (плоскогубцы) → новое стекло из запаса (точный drag в паз) → рамка *(в срезе — упрощённо)* |
| Расшатанная рукоять | болтается | разъединить → зачистить → клей / клин → собрать → просохнуть |
| Ржавчина | визуально + лупа | поверхностная — наждачка; средняя — растворитель + наждачка; глубокая — ванна; критическая — замена |

### Необычное

Предметы из мира: осколки с остаточными эмоциями, неизвестные материалы, технологии до-черноты, гибриды механики и органики. Поломки: почернение, неизвестный механизм (экспериментальный ремонт), эмоциональный остаток. См. [[Design/Blackness#Категория «Необычное»]].

## Процедуры ремонта — полные цепочки

### Пример 1: Карманный фонарь (электроника + бытовое) — полная версия

1. **Осмотр.** Корпус поцарапан, линза мутная, кнопка не нажимается. Лупа: в отсеке зелёный налёт (окисление), на линзе микротрещина, кнопка сидит криво.
2. **Разборка.** Открутить крышку (отвёртка). Извлечь батарейки (застряли — поддеть плоскогубцами). Открутить кольцо линзы (вращение вручную). Снять линзу. Два винта корпуса (отвёртка). Разделить половины.
3. **Диагностика внутренностей.** Лупа: провод к кнопке оплавлен, контактная пластина окислена, лампочка цела.
4. **Ремонт.** Зачистить контакты (мелкая наждачка, качание). Обрезать провод (кусачки), зачистить, припаять к кнопке (паяльник). Заменить линзу (drag в паз). Выправить кнопку (плоскогубцы).
5. **Сборка.** Обратный порядок: половины → винты → линза → кольцо → батарейки → крышка.
6. **Проверка.** Нажать кнопку. Свет ровный. Успех.

Жесты: вращение ×6, drag ×8, качание ×2, удержание ×1, точный drag ×1, зум ×2, клик ×1.

> [!important] Срез = упрощённый Пример 1
> В срезе фонарь имеет 5 модулей и 5 дефектов без пайки и точного drag: грязный корпус, окисленные контакты, погнутая кнопка, треснутая линза, севшие батарейки. Разборка — винты отвёрткой; замена — простой drag из запаса. Подробно — [[Systems/Items and Defects#Фонарь среза]].

### Пример 2: Ожерелье из пуговиц (текстиль + бытовое)

Осмотр (спутанный клубок: нить оборвана в двух местах, пуговица треснута, три отсутствуют, застёжка погнута, участок нити почернел) → **Распутывание** (8–12 медленных движений) → Ремонт нити (ножницы, игла, узел вращением, 6–8 протяжек) → Замена пуговиц (подбор по размеру: зелёная/красная подсветка; треснутую — заменить быстро или склеить с бонусом за оригинал) → Застёжка (плоскогубцы) → Узлы (вращение ×2) → **Проверка**: повесить на манекен, застегнуть.

Кандидат на **второй предмет** после плейтеста среза ([[Reference/MVP Scope#Критерий готовности среза]]).

### Пример 3: Музыкальная шкатулка (механика + бытовое + необычное)

Осмотр → Разборка (4 винта дна, извлечь механизм) → Диагностика (два язычка гребёнки сломаны, шестерня смещена, ось ржавая, петля согнута) → Ремонт механизма (наждачка, масло, шестерня на ось; язычки: замена гребёнки или подпилить — «звучит не как раньше, но звучит») → Корпус (плоскогубцы, шлифовка, лак, сушка) → Сборка → **Проверка**: завести ключом, открыть крышку. Возможный бонус: шкатулка «гудит» — тщательный ремонт сохраняет остаток, коллекционер заплатит втройне.

## Прогрессия сложности

| Этап | Предметы | Инструменты | Чернота | Цель |
|---|---|---|---|---|
| **Ранняя игра** (дни 1–5) | простые, 2–3 модуля, 1–2 поломки: бусы, фляга с вмятиной, тупой нож | отвёртка, плоскогубцы, тряпка, лупа, ножницы | нет или следы | научить жестам, дать удовлетворение от завершённого ремонта |
| **Средняя** (дни 6–15) | 3–5 модулей, 2–4 поломки: фонарь, шкатулка, часы, сумка с замком | + ключ, молоток, наждачка, игла, паяльник, кусачки, клей | лёгкая и средняя; растворитель, ванна | комбинации навыков, первые диагностические загадки |
| **Поздняя** (дни 16+) | 5–8 модулей, множественные поломки + чернота: протез, навигационный прибор, гибридное устройство | все + мультиметр, бормашина, набор от черноты | тяжёлая, многоэтапная | всё вместе: диагностика, стратегия, расходники, лор |

## Блокнот — замена гримуара

**Принцип:** в UCRS гримуар (318 страниц) написан кем-то до игрока. У мусорщика нет предшественника с мануалом. Блокнот — то, что игрок создаёт сам через опыт.

- Первый успешный ремонт нового типа поломки → **автоматическая зарисовка** от руки с пометками протагониста: «У фонарей серии К-4 контактная пластина держится на двух винтах, нижний всегда закисает».
- Стилизовано под почерк персонажа: кривовато, с сокращениями, иногда с ошибками («кажется, эта хрень называется реостат?»).
- Физическая книжка на столе, открывается по клику. Записи **хронологические**, как настоящие; оглавление — апгрейд «вкладки для блокнота».

Дополнительные источники знания:

- **Клиентские записки** — старьёвщик на рынке: «Этот таймер щёлкал и остановился» → подсказка к диагностике (щелчок = храповик, не пружина). На вылазке подсказок нет.
- **Чужие заметки как лут** — обрывки чьих-то ремонтных записей: лор + польза + объяснение, откуда знание в мире без Google.
- **Предметы-учебники** — фрагменты руководств до-чернотной эпохи, информация о необычных предметах.

> [!warning] Не в срезе
> Блокнот, записки, пайка, точный drag, удержание — за границей среза ([[Reference/MVP Scope#Границы скоупа]]).

## Качество ремонта

Качество 0–100 считается детерминированно: **40** за устранение всех дефектов + **30** за чистоту + **30** «аккуратность» минус штрафы за ошибки жестов (перекрут, лишние царапины — по 10). Формула и код — [[Systems/Items and Defects#Качество и цена]].

## Риск

Главный риск — переусложнить первый предмет. Если первый ремонт сразу требует 8–12 операций, игрок не успеет полюбить жесты. Поэтому срез: один предмет, явные и скрытые поломки, короткая проверка ([[Reference/Benchmarks/Uncle Chop's Rocket Shop#Риск для DustMan]]).
