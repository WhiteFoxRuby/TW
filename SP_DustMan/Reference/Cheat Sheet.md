## Управление

| Действие | Ввод |
|---|---|
| Ходьба в хабе | WASD / стрелки |
| Взаимодействие с точкой (рынок, верстак, прилавок) | **E** |
| Вернуться с верстака в хаб | **Q** (прогресс протирки/зачистки сохраняется) |
| Завершить ремонт (после пройденной проверки) | **E** / кнопка |
| Взять инструмент / деталь | ЛКМ drag со стола |
| Вернуть инструмент, отменить жест | **ПКМ** или клик по лотку |
| Осмотр (вращение фонаря) | ЛКМ drag по горизонтали |
| Зум | колесо мыши |
| Панель режиссёра | **F1** (хаб и верстак) |
| Сброс в `GestureDebug` | **R** |

| Компонент | Очки |
|---|---|

| Чистота (прогресс протирки корпуса; без дефекта грязи = 1) | до 30 |
| Аккуратность | 30 − 10 × (перекруты + царапины), не ниже 0 |
| **Итого** | 0–100, округление |

## Фонарь

`Lantern.asset`: 5 модулей (корпус, линза, лампа и контакты, батарейный отсек, кнопка), **2–3 дефекта** на экземпляр.

| Дефект | Виден | Инструмент → жест | Симптом | Приоритет |
|---|---|---|---|---|
| Грязный корпус | сразу | тряпка → протирка | — (цена) | 99 |
| Погнутая кнопка | сразу | плоскогубцы → клик + drag | кнопка не нажимается | 1 |
| Окисленные контакты | после разборки | наждачка → качание | не включается | 2 |
| Севшие батарейки | после разборки | запас → drag | не включается | 2 |
| Треснутая линза | только лупой | запас → drag | светит тускло | 3 |

Инструменты среза: отвёртка (вращение), плоскогубцы (drag), тряпка (протирка), наждачка (качание), лупа (зум).
