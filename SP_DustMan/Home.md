# DustMan («Мусорщик») — GDD Vault

2D side-scrolling игра про ручной ремонт в мире, где с неба регулярно падает орбитальный мусор. Протагонист — практичный мастер-ремонтник: находит хлам, чинит его жестами мыши за верстаком и продаёт, пока мир медленно поражает «чернота». Unity-проект: `DustMan`.

> Протагонисту не нужно быть героем. Ему нужно быть хорошим в своём деле. Игра делает мастерство достаточным.

## 🎯 Vision

> [!summary] Core Vision
> **Игра про ручной ремонт в ржавом, заваленном хламом мире.** Уютная коллекционерская философия Trash Goblin + диегетическая тактильность ремонта Uncle Chop's Rocket Shop + мифология эмоциональных объектов из Гачиакуты + выживательская эстетика болезни из Сабикуи Биско — в плотном дневном цикле **вылазка → ремонт → продажа**. Протагонист — не герой, а мастер: он не понимает метафизики мира, он просто аккуратен с вещами, и именно это делает его починенные предметы неуловимо другими.

Три столпа, которые ни один существующий тайтл не объединяет:

- **Диегетическая глубина ремонта.** Жесты мышью вместо кнопок: вращение для винтов, протирка для грязи, качание для наждачки. Диагностика без маркеров «вот тут сломано». См. [[Systems/Gestures]] и [[Systems/Repair]].
- **Осмысленный дневной дефицит.** 4 тайм-слота (модель Recettear): вылазка = 2, ремонт = 1, продажа = 1. Ни один день не вмещает всё. См. [[Systems/Day Cycle]].
- **Мир, где забота — тихая революция.** Предметы несут эмоциональный остаток; тщательный ремонт усиливает его, небрежный — убивает. Игра не объясняет это в лоб. См. [[Design/Blackness#Эмоциональный остаток]].

## 🧭 Корневая петля (one-liner)

Утро: рынок хлама или вылазка → День: верстак, три фазы ремонта (Осмотр → Работа → Проверка) → Вечер: прилавок, цена жестом, реакция покупателя → Ночь: сводка дня → новый день. Раз в неделю — аренда, событие недели, сдвиг спроса.

**В срезе:** купил фонарь за 15–25 → починил (качество 0–100) → продал за ~60 × (0.7…1.3). См. [[Reference/MVP Scope#Игровой цикл среза (walkthrough)]].

## 📐 Source of Truth

- **Жанр:** 2D side-scrolling симулятор ремонта и лавки с дневным циклом и системной болезнью мира.
- **Движок:** Unity 6000.3.8f1, URP 17.3, Input System 1.18, C#. Данные — ScriptableObject, UI — uGUI (собирается кодом).
- **Платформы:** PC (Steam), потенциально мобильные. Ориентация landscape. Модель — Premium.
- **Языки:** английский (приоритет), русский; на апдейт — японский, корейский, китайский.
- **Аудитория:** 18–35, любители инди и крафтинг-симуляторов.
- **Визуал:** flat 2D illustration, ретро-футуристический постапокалипсис; анимации — Spine/DragonBones; аудио — foley с упором на тактильность.
- **Исходники:** Unity-проект `D:\WORK\DustMan` (git, ветка `main`, первый коммит 2026-09-04). Документация проекта — `ProjectDocs/` там же (БГДД, блюпринт верстака, мир, механики починки, визуал, AI-режиссёр, DirectorBench, декомпозиции, WORKLOG, ревью 2026-09-04). Исходные `.docx` — `ProjectDocs/incoming-files/`.

> [!note] Состояние на 2026-09-04
> Вертикальный срез собран (этапы 0–5 скоупа): данные, жесты, верстак с фонарём, экономика день-цикла. Поверх него — каркас AI-режиссёра с телеметрией, policy-контрактом, валидатором, библиотекой блоков и headless-симулятором. **Ручная приёмка этапов в редакторе не проводилась.** Ревью кодовой базы: тестов нет, у режиссёра два расхождения между задуманной и фактической архитектурой. Подробно — [[Reference/Roadmap]].
