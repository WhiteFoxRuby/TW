# Дизайн-документация DustMan («Мусорщик»)

Собственная дизайн-документация проекта. Перенесена из docx-файлов `incoming-files` 2026-07-08.

## Файлы

- [MVP-скоуп: вертикальный срез](./mvp-scope.md) - что строим первым, этапы с критериями приёмки, правила для агента-разработчика. **Начинать отсюда.**
- [Базовая гейм-дизайн документация (БГДД)](./gdd.md) - технические требования, кор-геймплей, мета, циклы.
- [Верстак мусорщика: единый блюпринт](./workbench-blueprint.md) - подробный разбор поиска, продажи, ремонта и того, как референсы складываются в концепцию.
- [Мир падающего неба](./world.md) - научное обоснование сеттинга: архитектура, вода и еда, мусорные горы, технологии.
- [AI-режиссёр](./ai-director.md) - система управления темпом: входные параметры, индексы, ручки. Черновик.
- [Neural Director Roadmap](./neural-director-roadmap.md) - план перехода от rule-based режиссёра к GRU/Transformer по истории событий.
- [Глоссарий](./glossary.md) - ключевые термины проекта.
