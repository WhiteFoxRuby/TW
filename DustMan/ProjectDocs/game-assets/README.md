# Ассеты игры

В этой папке будет храниться каталог ассетов игры: описания, ссылки на исходники, статусы и связь с фичами.

Фактические Unity-ассеты, которые должны использоваться в игре, остаются в `Assets`. Эта папка нужна для учета, описаний и материалов, которые еще не готовы к импорту.

## Документы

- [Визуальная стилистика](./visual-style.md) - стиль, палитра, персонаж, фоны, адаптация мира, социальные ярусы.
- [Промты визуала](./visual-prompts.md) - промты для генерации фонов и других ассетов.

## Разделы ассетов

| Раздел | Описание | Статус |
| --- | --- | --- |
| Визуальные ассеты | Спрайты, изображения, UI-графика, эффекты | Стайлгайд готов: [visual-style.md](./visual-style.md) |
| Звуки | Музыка, SFX, голоса | Не заполнено |
| Сцены и префабы | Игровые сцены, объекты, шаблоны | Не заполнено |
| Материалы и настройки | Материалы, render-настройки, конфиги | Не заполнено |
