# Декомпозиция референс-игр

В этой папке лежат разборы референсов для DustMan. Цель разборов - не пересказать игры, а выделить системы, циклы, интерфейсные решения и то, что можно перенести в проект.

## Файлы

- [Uncle Chop's Rocket Shop](./uncle-chops-rocket-shop.md) - диегетический ремонт, процедурные поломки, мануал, давление времени.
- [Reshine](./reshine.md) - расслабленная реставрация, предмет как медитативный процесс, отсутствие менеджмента.
- [Trash Goblin](./trash-goblin.md) - поиск, чистка, апсайклинг, продажа, магазин и коллекционирование.

## Формат декомпозиции

Каждый файл разбирает:

1. Основную фантазию игрока.
2. Кор-цикл и сессионный цикл.
3. Подсистемы игры.
4. Как система работает по шагам.
5. Что полезно для DustMan.
6. Что лучше не переносить напрямую.

## Источники

Источники указаны внизу каждого файла. Разборы сделаны 2026-06-28 по публичным страницам Steam, публичным материалам по плейтесту Reshine и загруженным проектным документам из `ProjectDocs/incoming-files`.
