# Служебный файл для Codex

Этот файл нужен ассистенту как рабочая память по документации проекта.

## Правила

- Документация проекта хранится в `ProjectDocs`, вне Unity-папки `Assets`.
- Не переносить эти файлы в `Assets`, чтобы Unity не импортировала документацию.
- При добавлении нового документа обновлять [главное содержание](../README.md).
- При выполнении заметной работы добавлять запись в [журнал работ](../WORKLOG.md).
- Собственную дизайн-документацию игры (GDD, системы, мир, глоссарий) хранить в [design](../design/README.md).
- Фичи описывать отдельными `.md` файлами в [features](../features/README.md).
- Декомпозиции референсов хранить в [decomposition](../decomposition/README.md).
- Ассеты игры описывать и каталогизировать в [game-assets](../game-assets/README.md).
- Файлы, принесенные пользователем с Google Drive, сначала учитывать в [incoming-files](../incoming-files/README.md).
- Исследовательские материалы (бенчмарки, эксперименты) хранить в [research](../research/README.md).
- Термины проекта (чернота, тайм-слоты и т.д.) сверять с [глоссарием](../design/glossary.md).

## Точка входа для разработки

Агенту-разработчику начинать с [design/mvp-scope.md](../design/mvp-scope.md): там границы скоупа, этапы с критериями приёмки и правила работы с кодом.
