# Подгружаемые файлы

Сюда можно складывать файлы, которые сейчас находятся на Google Drive, перед тем как они будут разобраны и перенесены в постоянные разделы документации.

## Правила разбора

- Не удалять исходные файлы отсюда, пока они не разобраны и не отмечены в документации.
- После разбора указать, куда перенесена информация или ассет.
- Если файл относится к фиче, добавить ссылку в [фичи проекта](../features/README.md).
- Если файл относится к игровым ассетам, добавить ссылку в [ассеты игры](../game-assets/README.md).
