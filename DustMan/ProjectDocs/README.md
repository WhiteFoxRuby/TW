# Документация DustMan

Эта папка хранит проектную документацию и рабочие материалы вне `Assets`, поэтому Unity не должна импортировать эти файлы и создавать для них `.meta`.

## Содержание

- [Служебный файл для Codex](./_service/CODEX.md) - правила и рабочий контекст для ассистента.
- [Ревью проекта 2026-09-04](./_service/code-review-2026-09-04.md) - разбор кодовой базы среза: находки по значимости и порядок работ.
- [Журнал работ](./WORKLOG.md) - записи о том, что было сделано в проекте.
- [Дизайн-документация](./design/README.md) - БГДД, блюпринт верстака, мир, глоссарий.
- [Исследования](./research/README.md) - исследовательские материалы: DirectorBench (бенчмарк ИИ-режиссёра).
- [Подгружаемые файлы](./incoming-files/README.md) - место для файлов, которые будут перенесены с Google Drive.
- [Декомпозиция референсов](./decomposition/README.md) - разбор систем, циклов и решений в референс-играх.
- [Фичи проекта](./features/README.md) - список фич и ссылки на их описания.
- [Ассеты игры](./game-assets/README.md) - структура и описание игровых ассетов.

## Как поддерживать

1. Все новые документы добавлять в подходящую папку внутри `ProjectDocs`.
2. После добавления файла обновлять этот список-содержание.
3. Значимые изменения по проекту записывать в [журнал работ](./WORKLOG.md).
4. Файлы из Google Drive сначала складывать в [incoming-files](./incoming-files/README.md), а затем разносить по нужным разделам.
